Nhánh chứa các Component của Homepage, ErrorPage và Login
+ Mã nguồn của trang homepage, ErrorPage, trang login(test thử)
+ Các Component phụ cần thiết + API cần thiết cho Homepage

- Depedencies đã có sẵn trong file package.json
- Sử dụng node.js, tải thư mục này về và sử dụng lệnh 'npm install' để tải các dependencises cần thiết
- chạy 'npm run dev' để chạy ứng dụng web trên localhost
